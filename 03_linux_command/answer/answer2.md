Q. 相対パスでの移動
step1. ホームディレクトリの「Question」フォルダの中に「A」と「B」という2つのフォルダを作り、
        さらにその中に「A/X」「B/Y」というフォルダも作る
step2. 「A/X」フォルダに移動する
step3. 「A/X」から、絶対パスやホームディレクトリ（~）を使わず、相対パスだけで「B/Y」フォルダに移動する
step4. pwd で「B/Y」に移動できたことを確認する

```bash
# 「Question」フォルダへ移動する（演習1で作成済み）
cd ~/Question

# 「A/X」と「B/Y」フォルダを作る（-p で親フォルダごと一括作成）
mkdir -p A/X
mkdir -p B/Y

# 「A/X」フォルダへ移動する
cd A/X

# 相対パスだけで「B/Y」フォルダへ移動する
# 「../..」で2つ上の階層（Question）に戻り、そこから B/Y に入る
cd ../../B/Y

# 確認する
pwd
# → .../Question/B/Y のように表示されればOK
```

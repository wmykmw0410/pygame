# 練習1: 現在地の確認と移動

README の「現在地を確認する」「ディレクトリの中身を見る」「ディレクトリを移動する」を見ながら、「★」の部分のコマンドを、自分の端末のターミナルで自分で打ち込もう。
この練習は、見る・移動するだけなので、ファイルは変更されない。

## 手順

```bash
# ★ ホームディレクトリに移動する

# ★ 現在地を確認する

# ★ 中身を一覧表示する

# ★ 詳細表示（-l）で一覧表示する

# ★ 隠しファイルも表示（-a）して一覧表示する

# ★ 1つ上の階層に移動して、現在地を確認する

# ★ ホームディレクトリに戻る
```

## 試してみよう

実行する前に、結果を予想してみよう（1つ試したら、ホームディレクトリに戻ってから次へ）。

1. `ls` → `ls -l` → `ls -a` の順に打つ → 表示はどう違う?
2. `cd ..` を2回打って、そのたびに `pwd` で確認する → どこに移動した?
3. `cd /` を打って `pwd` と `ls` を打つ → ここはどこ?
4. `/` にいる状態でもう一度 `cd ..` を打って `pwd` を確認する → どうなる?
5. `cd ~` のあとに `cd /` を打ち、さらに `cd -` を打つ → どこに戻る?
6. 存在しない名前（例: `cd abc`）を打つ → どうなる? その後 `pwd` で現在地を確認する

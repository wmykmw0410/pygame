# 練習3: ファイルの内容を書き込む・確認する

README の「ファイルの内容を確認・書き込む」を見ながら、「★」の部分のコマンドを、自分の端末のターミナルで自分で打ち込もう。

## 準備

```bash
cd ~
mkdir -p Practice
cd Practice
```

## 手順

```bash
# ★ 「hello」という文字列を memo.txt に書き込む

# ★ memo.txt の内容を表示する

# ★ 「world」という文字列を memo.txt に追記する

# ★ memo.txt の内容を表示する

# ★ memo.txt の内容を、行番号つきで表示する
```

## 試してみよう

実行する前に、結果を予想してみよう。

1. 追記ではなく、もう一度 `echo 文字列 > memo.txt`（`>` が1つ）を打つ → `cat` で見ると、中身はどうなる?
2. `>>` を何度か続けて打つ → 行はどうなる? `cat -n` で見ると?
3. まだ存在しないファイル名に `echo 文字列 > new.txt` を打つ → ファイルはどうなる? `ls` で確認する
4. `echo 文字列` だけ（`>` を付けない）を打つ → どこに表示される? ファイルは変わる?

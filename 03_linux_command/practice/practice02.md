# 練習2: フォルダとファイルを作る・消す

README の「ディレクトリを作成・削除する」「ファイルを操作する」を見ながら、「★」の部分のコマンドを、自分の端末のターミナルで自分で打ち込もう。
`rm` で消したファイルは元に戻せないので、**この練習は必ず下の「Practice」フォルダの中だけで行う**（自分で作ったものしか消さない）。

## 準備

```bash
cd ~
mkdir -p Practice
cd Practice
```

## 試してみよう

実行する前に、結果を予想してみよう。エラーが出ても、そのまま次へ進んでよい。

1. `mkdir x/y/z` を、`-p` を付けずに打つ → どうなる? `-p` を付けると?
2. すでにある `sub` と同じ名前で、もう一度 `mkdir sub` を打つ → どうなる?
3. 中にファイルがあるフォルダに `rmdir` を打つ → どうなる? 空のフォルダなら?
4. フォルダに、`-r` を付けずに `rm` を打つ → どうなる?
5. `cp` のあとに `ls` を打つ → ファイルはいくつある? `mv` で名前を変えたあとは?
6. `mv` で、ファイルを別のフォルダの中へ移動する → 元の場所と移動先の `ls` はどうなる?
7. `rm -i ファイル名` を打って、`n` と `y` をそれぞれ入力する → どうなる?

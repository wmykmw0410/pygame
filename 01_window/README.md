# pygame とは

`pygame` は、Python でゲームを作るための外部ライブラリ。標準ライブラリには含まれないので、使う前に一度だけ次のコマンドでインストールしておく。

```text
pip install pygame
```

`ModuleNotFoundError: No module named 'pygame'` と出たら、インストールできていない。[00_setup](../00_setup/README.md) を確認する。

ウィンドウの表示、図形・画像・文字の描画、キーボードやマウスの入力の取得、音声の再生といった「ゲームに必要な機能」をひとまとめに提供してくれる。

ゲーム画面は、パラパラ漫画のように**1枚の絵を描いて表示する処理を高速に繰り返す**ことで、動いているように見せている。この章で作る「ずっとループする」構造がその繰り返しの部分で、`pygame` はループの中で使う「画面を初期化する」「絵を描く」「入力を調べる」「画面を表示する」といった道具（関数）を提供している。

---

# ゲームプログラムの構造

ゲームのプログラムは、大きく2つの部分でできている。

```text
■ 準備部分（プログラム開始時に1回だけ実行される）
    ライブラリの読み込み、ウィンドウの作成など

■ ループ部分（ウィンドウを閉じるまで、ずっと繰り返される）
    画面を初期化する → 絵を描く・判定する → 画面に表示する → 入力を調べる
```

この「同じ処理を繰り返す部分」を**ゲームループ**と呼ぶ。1回のループが「1フレーム」＝パラパラ漫画の1コマにあたり、これを1秒間に何十回も繰り返すことでキャラクターが動いて見える。`clock.tick(FPS)`はこの「1秒間に何コマ描くか（FPS）」を一定に保つための仕組み。

準備部分は**一度だけ**でよい処理（ウィンドウを開く、画像を読み込む、など）を書き、ループ部分は**毎フレーム繰り返す**処理を書く、という役割分担を覚えておくと、この後のレッスンでコードの置き場所に迷いにくくなる。

## 準備部分に書くこと

準備部分には「ゲームが始まる前に1回だけ済ませておきたい処理」を書く。このレッスンでは次の6つが該当する（対応するステップはステップ1）。

| 処理 | 対応するコード |
| --- | --- |
| ライブラリの読み込み | `import pygame as pg` |
| pygame 全体の初期化 | `pg.init()` |
| 画面サイズ・FPSの定数を定義する | `WIDTH, HEIGHT = 800, 600` / `FPS = 60` |
| ウィンドウの作成 | `screen = pg.display.set_mode((WIDTH, HEIGHT))` |
| タイトルの設定 | `pg.display.set_caption("タイトル名")` |
| FPS管理用のタイマー作成 | `clock = pg.time.Clock()` |

この後のレッスンでは、ここに「画像・音声ファイルの読み込み」「スコアやプレイヤーの位置など、ゲームで使う変数の初期値」も加わっていく。何が準備部分に入るかを迷ったら、「**毎フレーム繰り返す必要がなく、ループに入る前に1回やっておけば済む処理か**」で判断するとよい。

## ループ部分に書くこと

ループの中も、さらに役割ごとに分かれている。

| 役割 | このレッスンでの対応ステップ |
| --- | --- |
| 前のフレームの絵を消して、画面をきれいにする | ステップ3 |
| 今のフレームの絵を描く・当たり判定などを行う | ステップ4 |
| 描いた絵をまとめて画面に映す | ステップ5 |
| キー入力やウィンドウを閉じる操作を確認する | ステップ6・7 |

「初期化する → 描く → 表示する → 入力を調べる」というこの順番と役割分担は、以降のレッスンでも共通して使う型になる。

## ステップ1.ゲームを準備する
```python
# ライブラリのimportをする
import ライブラリ名

# importしたライブラリやモジュールに省略名をつける
import ライブラリ名 as 省略名


# pygameでは最初に初期化を行う
pg.init()

# ウィンドウの大きさとFPSを定数にしておく（変えないつもりの値は全て大文字にする）
WIDTH, HEIGHT = 800, 600
FPS = 60

# 初期化をしたらゲーム用のウィンドウを作る(横800 x 縦600)
# 戻り値は変数screenに入れる
# このプログラムはscreenに対してゲーム画面を描いていく
screen = pg.display.set_mode((WIDTH, HEIGHT))

# ウィンドウのタイトルバーに表示する文字列を設定する
pg.display.set_caption("タイトル名")

# FPS(Frames Per Second)を管理するClockオブジェクトを作る
# FPSとは1秒間に画面を何回更新するかを表す値
# 値が大きいほど滑らかになるが、処理負荷も上がる
clock = pg.time.Clock()
```

このレッスンでは `import pygame as pg` に加えて、終了処理（`sys.exit()`）で使う `import sys` も読み込む。`import sys` を忘れると、閉じるボタンを押したときに `NameError: name 'sys' is not defined` というエラーになる。

`pg.init()` のように「名前(引数)」で処理を呼び出すものを**関数**という。戻り値があれば `screen = pg.display.set_mode(...)` のように変数で受け取る。

| 呼び出し方 | 引数 | 戻り値 | 役割 |
| --- | --- | --- | --- |
| `pg.init()` | なし | 使わない | pygame 全体を初期化する |
| `pg.display.set_mode((WIDTH, HEIGHT))` | ウィンドウの (幅, 高さ) | ウィンドウ本体（`screen`） | ウィンドウを作る |
| `pg.display.set_caption("タイトル")` | タイトル文字列 | 使わない | タイトルバーの文字を設定する |
| `pg.time.Clock()` | なし | Clockオブジェクト（`clock`） | FPS管理用のタイマーを作る |

`pg.〇〇` の「.」は「`pg` モジュールの関数」という意味。「モジュール名.関数名()」の形は今後もよく出てくる。`screen` と `clock` はこの先もずっと使う変数。

`WIDTH`, `HEIGHT`, `FPS` のように、変えないつもりの値は慣習で**全て大文字**にする。1箇所にまとめておけば、後で値を変えたいときにそこだけ直せばよい。

## ステップ3.画面を初期化する
```python
# 繰り返しの中に入ったら、初めに画面をきれいに消す
# screenにfill関数で塗りつぶしを行う
# pg.Color("WHITE")で白を指定して、真っ白に塗りつぶす
screen.fill(pg.Color("WHITE"))
```

`screen.fill(色)` も関数（`screen` のメソッド）。

---

## ステップ4.絵を描いたり、判定したりする
```python
# 真っ白になったゲーム画面に、赤い四角形を描く
# pygameのdraw.rect関数で四角形を描く
pg.draw.rect(screen, pg.Color("RED"), (100, 100, 100, 150))
pg.draw.rect(screen, pg.Color("色"), (x座標, y座標, 幅, 高さ))
```

`pg.draw.rect(描画先, 色, (x, y, 幅, 高さ))` は四角形を描く関数。

---

## ステップ5.画面を表示する
```python
# 画面に描くという処理はコンピュータにとって時間がかかるため
# 裏側（メモリ内）で絵を描いておき（screen）、全部できてから一気に表示させる
pg.display.update()

# clock.tick(fps)でFPSを制御する
# ステップ1で定義した FPS(=60) を渡すと、1秒間に最大60回ループが回るよう速度を調整する
#   デフォルト値: 0（制限なし、できる限り高速で実行）
#   範囲: 0以上の整数（推奨: 30〜60）
clock.tick(FPS)
```

`pg.display.update()` は画面に反映する関数。`clock.tick(FPS)` はループ回数をFPSに制限する関数。

---

## ステップ6.ユーザからの入力を調べる
```python
# キーボードやマウスから発生したイベントをpg.event.get()で受け取り
# for文で1つずつevent変数に取り出して調べる
# ※ 閉じるボタンの検出（ステップ7）もここで行う
# ※ 画面を表示し終えた後、次のループに入る前にここで調べる
for event in pg.event.get():
    if event.type == pg.QUIT:
        pg.quit()
        sys.exit()
```

`pg.event.get()` は発生したイベントをリストで返す関数。

---

## ステップ7.閉じるボタンが押されたら、終了する
```python
# ステップ6のイベントループ（for event in pg.event.get()）の中に書く
# ユーザがウィンドウの「閉じる」ボタンを押すと
# 「何かが押された」というお知らせがくる（イベント）
# 「押されたものが何か（event.type）」を調べて
# pg.QUITであれば pg.quit()でpygameを終了し、sys.exit()でプログラムを終了する
if event.type == pg.QUIT:
    pg.quit()
    sys.exit()
```

`pg.quit()` は pygame を終了する関数。

# Python 文法リファレンス

このリポジトリのレッスンを進めるうえで必要になる Python の文法を、**基礎・中級・発展**の3段階に分けたリファレンス集。レッスンのように順番にやる必要はなく、分からない文法が出てきたときに辞書的に参照する使い方を想定している。

| レベル | ファイル | 内容 |
| --- | --- | --- |
| 基礎 | [01_basic.md](01_basic.md) | 変数・型・演算子・文字列・制御構文・リスト・タプル・集合・辞書 |
| 中級 | [02_intermediate.md](02_intermediate.md) | 関数（`*args`/`**kwargs` を含む）・組み込み関数・クラス・継承・例外処理・モジュール |
| 発展 | [03_advanced.md](03_advanced.md) | ファイルの読み書き（`with`/`open()`）・JSON・lambda・`zip()`・標準ライブラリ・venv |

## 到達目標との対応

このリポジトリの学習到達目標は「Python 3 エンジニア認定基礎試験に合格できるレベル」。3ファイルの内容は、公式チュートリアルの章立てにおおよそ次のように対応する（詳細は [CURRICULUM_SCOPE.md](../../CURRICULUM_SCOPE.md) を参照）。

- **基礎**: 公式チュートリアル 3章（形式ばらない紹介）・4章（制御構文）・5章（データ構造）相当
- **中級**: 6章（モジュール）・9章（クラス）・8章（エラーと例外）相当
- **発展**: 7章（入出力）・13章（仮想環境とパッケージ）相当

## 使い方

- コード中に知らない書き方が出てきたら、目次から探して該当セクションを読む。
- 発展編の内容（`with`/`zip()` など）は、実際にこのリポジトリのコード（例: `21_super_mario` の `load_stage()`）ですでに使われている。「動いているコードで見た書き方を、ここで概念として理解し直す」という読み方もできる。
